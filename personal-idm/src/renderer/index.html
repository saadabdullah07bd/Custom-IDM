Download Scheduler — Queue & Timed Automation
Status: Timed Scheduling Not Yet Implemented in Current Build
Intended Feature Purpose

The IDM Scheduler is designed for scheduling downloads and managing timed download queues automatically:

  • Start and stop download queues at scheduled clock times or days of the week.
  • Limit active concurrent downloads per queue and retry failed transfers automatically.
  • Perform post-completion actions (such as disconnecting network or exiting Personal IDM).

Current Availability: Automated time-based triggers are not yet enabled. You can manually start and stop the active download queue at any time using the Start Queue and Stop Queue buttons on the main toolbar.

IDM Site Grabber — Website Resource Collector
Status: Website Crawling Not Yet Implemented in Current Build
Intended Feature Purpose

The IDM Site Grabber is intended for collecting downloadable resources from websites using customizable link-following and file-type filters:

  • Explore a target URL up to a specified link depth across same-domain or external pages.
  • Collect all matching audio, video, archive, image, or document assets for batch queuing.
  • Mirror website directory structures for offline browsing.

Current Availability: Full multi-page website crawling is not yet available. To download direct file links immediately, click Add URL on the toolbar or use the Personal IDM Browser Extension context menu.
